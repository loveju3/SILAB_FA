MODEL TRAINING

訓練、比較，保存每次進步。

選擇資料與運算環境，追蹤訓練進度，對照相同驗證段的結果。

只使用開發用 history；依時間與近似模板切分訓練／驗證段。切換頁面或重新整理不會停止背景工作，訓練未套用 2 GB 限制。

CPU 使用目前的 Python 環境，不需 GPU。
自動建立「台北日期時間戳＋唯一編號」資料夾，保存資料快照、設定、紀錄與 models/，不覆寫舊模型。
小資料保守設定

另固定 batch=8、512 tokens、seed=42、梯度裁切=1、10% warmup，驗證六類 F1 連續 2 epochs 未改善即停止，保留最佳 checkpoint。低學習率與正規化不能保證不過擬合；下方會保留訓練／驗證差距。比較用 checkpoint 不以完整 history 重訓。

同時只允許一個訓練工作；不會讀取 dev 或覆寫既有模型。
